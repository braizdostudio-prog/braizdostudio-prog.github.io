Política de Privacidade – Warcarta

Última atualização: 6 de maio de 2026

1. Introdução

O Warcarta ("o Aplicativo") respeita a sua privacidade. Esta Política de Privacidade explica como os dados são coletados, usados e compartilhados quando você utiliza o Aplicativo.

2. Coleta de dados

O Aplicativo não exige registro do usuário e não coleta diretamente informações de identificação pessoal, como nome, endereço de e-mail ou número de telefone.

No entanto, serviços de terceiros integrados ao Aplicativo podem coletar automaticamente determinados dados.

a) Dados de publicidade (Google AdMob)

O Aplicativo utiliza o Google AdMob para exibir anúncios. O AdMob pode coletar e processar os seguintes dados:

  • ID de publicidade
  • Identificadores do dispositivo
  • Endereço IP
  • Localização aproximada
  • Interações no app (visualizações e cliques em anúncios)
  • Dados do dispositivo e de desempenho

Finalidade:

  • Publicidade e marketing
  • Análise
  • Prevenção de fraudes

b) Dados de diagnóstico e falhas (Microsoft Application Insights)

O Aplicativo utiliza o Microsoft Application Insights para monitorar o desempenho e detectar erros.

Os dados coletados podem incluir:

  • Registros de falhas e relatórios de erro
  • Informações do dispositivo (modelo, versão do sistema operacional)
  • Dados de uso (desempenho do app, atividade da sessão)
  • Endereço IP (pode ser anonimizado)

Finalidade:

  • Análise
  • Funcionalidade e estabilidade do app

3. Compartilhamento de dados

Os dados coletados podem ser compartilhados com:

  • Google (AdMob – publicidade, análise)
  • Microsoft (Application Insights – análise e diagnóstico)

Esses terceiros processam os dados de acordo com suas próprias políticas de privacidade.

4. Segurança dos dados

Os dados são transmitidos por meio de criptografia segura (HTTPS). Medidas razoáveis são implementadas para proteger os dados coletados.

5. Retenção e exclusão de dados

Os dados são mantidos apenas pelo tempo necessário para as finalidades descritas acima. Os usuários podem nos contatar para solicitar a exclusão, quando aplicável.

6. Direitos do usuário (RGPD)

Se você estiver localizado no Espaço Econômico Europeu (EEE), você tem o direito de:

  • Acessar seus dados
  • Solicitar correção ou exclusão
  • Opor-se ao processamento

Para exercer seus direitos, contate-nos em: braizdo.studio@gmail.com

7. Privacidade infantil

O Aplicativo não é direcionado a crianças menores de 13 anos. Se você acredita que uma criança forneceu dados, entre em contato conosco.

8. Consentimento (usuários do EEE)

Para usuários no EEE, uma solicitação de consentimento pode ser exibida em relação à publicidade personalizada, em conformidade com o RGPD.

9. Alterações a esta política

Esta Política de Privacidade pode ser atualizada. As alterações serão publicadas nesta página.

10. Contato

Para qualquer dúvida: braizdo.studio@gmail.com
