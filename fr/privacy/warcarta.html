Politique de confidentialité – Warcarta

Dernière mise à jour : 6 mai 2026

1. Introduction

Warcarta (« l'Application ») respecte votre vie privée. Cette politique de confidentialité explique comment les données sont collectées, utilisées et partagées lorsque vous utilisez l'Application.

2. Collecte des données

L'Application ne nécessite pas d'inscription et ne collecte pas directement d'informations personnelles identifiables telles que le nom, l'adresse e-mail ou le numéro de téléphone.

Cependant, des services tiers intégrés à l'Application peuvent collecter automatiquement certaines données.

a) Données publicitaires (Google AdMob)

L'Application utilise Google AdMob pour afficher des publicités. AdMob peut collecter et traiter les données suivantes :

  • Identifiant publicitaire
  • Identifiants de l'appareil
  • Adresse IP
  • Localisation approximative
  • Interactions dans l'application (affichages, clics sur les publicités)
  • Données sur l'appareil et les performances

Finalités :

  • Publicité et marketing
  • Analyse d'audience
  • Prévention de la fraude

b) Données de diagnostic et de plantage (Microsoft Application Insights)

L'Application utilise Microsoft Application Insights pour surveiller les performances et détecter les erreurs.

Les données collectées peuvent inclure :

  • Journaux de plantage et rapports d'erreur
  • Informations sur l'appareil (modèle, version du système)
  • Données d'utilisation (performances de l'application, activité de session)
  • Adresse IP (pouvant être anonymisée)

Finalités :

  • Analyse d'audience
  • Fonctionnement et stabilité de l'application

3. Partage des données

Les données collectées peuvent être partagées avec :

  • Google (AdMob – publicité, analyse d'audience)
  • Microsoft (Application Insights – analyse et diagnostic)

Ces tiers traitent les données conformément à leurs propres politiques de confidentialité.

4. Sécurité des données

Les données sont transmises via un chiffrement sécurisé (HTTPS). Des mesures raisonnables sont mises en œuvre pour protéger les données collectées.

5. Conservation et suppression des données

Les données sont conservées uniquement le temps nécessaire aux finalités décrites ci-dessus. Les utilisateurs peuvent nous contacter pour demander leur suppression, le cas échéant.

6. Droits des utilisateurs (RGPD)

Si vous résidez dans l'Espace économique européen (EEE), vous avez le droit de :

  • Accéder à vos données
  • Demander leur rectification ou leur suppression
  • Vous opposer à leur traitement

Pour exercer vos droits, contactez-nous à : braizdo.studio@gmail.com

7. Confidentialité des enfants

L'Application ne s'adresse pas aux enfants de moins de 13 ans. Si vous pensez qu'un enfant nous a communiqué des données, veuillez nous contacter.

8. Consentement (utilisateurs de l'EEE)

Pour les utilisateurs situés dans l'EEE, une demande de consentement peut être affichée concernant la publicité personnalisée, conformément au RGPD.

9. Modifications de cette politique

Cette politique de confidentialité peut être mise à jour. Les modifications seront publiées sur cette page.

10. Contact

Pour toute question : braizdo.studio@gmail.com
